# Independent devnet pilot

This trial checks whether a person who did not build Toluva can use the public product. It is product testing, not a claim of organic traction or a funded campaign. Record only transactions that really finalize on Solana devnet.

## Participant path

1. Open [devnet.toluva.xyz](https://devnet.toluva.xyz), connect a Solana wallet set to devnet, and open a live DBC launch. The current [Toluva Genesis launch](https://devnet.toluva.xyz/launches/TLVGEN-BYZ9FJMNNJKRPVGPWGCCOTUZSLAODDKMKMDHWVP7CXGV) is available while its curve remains open; the test should also work on any other active launch.
2. Read the token details, graduation target, fees, liquidity commitments, and on-chain address links. Confirm that the live pool status is fresh. Note anything that is unclear without coaching.
3. Enter a small devnet SOL amount, review the estimated and minimum tokens, and sign a buy in the wallet. If the participant prefers, stop before signing and record only the read-only usability result.
4. After a signed buy, keep the transaction signature. Check that the UI shows a confirmation and, after finalization, the public verified-activity card includes the trade exactly once. Refresh the page and check the same result again.
5. If the participant chooses to test selling, review a fresh sell quote and sign the sell. Check that the verified activity counts and wallet balance change match the transactions. Do not require a sell from a participant who wants to hold tokens.

## Evidence to keep

- Launch page URL, network, participant wallet public address, and a short account of steps completed without assistance.
- Buy and optional sell signatures, finalized status, actual input/output amounts, and the pool/mint those transactions touched.
- Any confusing copy, wallet prompt, delayed status, or error message, including the user's understanding of how to recover.
- A screenshot of the public page after verification if the participant is comfortable sharing it.

The participant must approve all wallet actions personally. Use devnet assets only. Never request a private key, seed phrase, or wallet export. If a transaction's result is uncertain, check its signature on a devnet explorer before initiating another trade. A separate participant wallet is needed for independent-use evidence; the creator wallet cannot establish that claim.

## Pass criteria

An independent person can find a launch, understand the terms, connect a wallet, review a current quote, complete a wallet-signed trade, and see a matching finalized on-chain record and verified activity without developer intervention. Any failure becomes a reproducible product issue before a mainnet trial.
